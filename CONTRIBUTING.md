# Contributing to routetheoc

Thanks for your interest in contributing!

## Getting Started

1. Fork the repo
2. Clone your fork
3. `cp .env.example .env` and edit if needed
4. `npm install`
5. `npm start`

## Making Changes

- Keep it simple — single-file server, no frameworks
- Test locally against the upstream catalog before submitting
- Open an issue first for big changes

## Pull Requests

- One feature/fix per PR
- Describe what changed and why
- Make sure `node server.js` starts without errors

## Reporting Issues

Include:
- What you expected
- What happened
- Steps to reproduce
- Node version (`node -v`)
